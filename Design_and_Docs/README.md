CAMSECURE is Cameroon's first unified missing persons and family reunion platform. It combines a React web app, DeepFace AI facial recognition, QR-based safe-contact identification, and GPS tracking devices (wristbands, tags, pendants) to help families locate missing relatives during the critical first hours of a disappearance. The system features a geolocation alert engine, a free MTN emergency helpline, and a partner portal for police, hospitals, and schools — all built on Node.js, Supabase, and Netlify.
